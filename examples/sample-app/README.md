# sample-app

Proyecto minimal que muestra la capa de proyecto tras `/flujo-init`. Sirve de referencia y de prueba viva del inicializador.

Contiene la estructura esperada: `.claude/`, `docs/` (Diataxis + ADR + C4), `specs/`, `gauntlet.json`, `dod.json`, CI.

Para regenerarlo desde cero: instalar `flujo-core` y ejecutar `/flujo-init` en un repo vacio.
